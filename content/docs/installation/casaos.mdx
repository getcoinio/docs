---
title: CasaOS
description: Install Coinio with CasaOS custom install.
---

The compose file is [`deploy/casaos/docker-compose.yml`](https://raw.githubusercontent.com/getcoinio/coinio/main/deploy/casaos/docker-compose.yml). It stores data in `/DATA/AppData/coinio`.

<Steps>
<Step>

In CasaOS, open **App Store › Custom Install**, click **Import** and paste the contents of the compose file.

</Step>
<Step>

Check the port (8080 by default) and click **Install**. Open Coinio from the dashboard and create your account.

</Step>
</Steps>
