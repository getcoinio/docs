## What every method has in common

| | |
| --- | --- |
| Image | `ghcr.io/getcoinio/coinio:latest` |
| Port | `8080` (web app, API and MCP endpoint) |
| Data | `/data` (database and logos) |
| User | runs as UID `1000`, not root (it takes over a root-owned data folder on start) |

After installing, open `http://<server-ip>:8080` and continue with [First run](/docs/first-run).
