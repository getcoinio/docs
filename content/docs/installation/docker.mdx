---
title: Docker
description: Run Coinio with a single docker run command.
---

```sh
docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  ghcr.io/getcoinio/coinio:latest
```

Open `http://<server-ip>:8080` and create your account.

- `-v coinio-data:/data` keeps the database and logos in a named volume, so they survive updates. Docker creates it with the right owner.
- `-p 8080:8080` publishes the web app. To use another host port, change only the left side, for example `-p 9000:8080`.

## Settings

Pass [environment variables](/docs/reference/configuration) with `-e`. The one you will most likely need is your public https address, once you have one:

```sh
docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  -e COINIO_PUBLIC_URL=https://coinio.example.com \
  ghcr.io/getcoinio/coinio:latest
```

`COINIO_PUBLIC_URL` should start with `https://`. With a plain `http://` address the app starts, but remote MCP clients cannot sign in. See [Expose to the internet](/docs/expose).

## Checking it

```sh
docker ps --filter name=coinio
docker logs coinio
```

The image has a health check on `/api/health`, so `docker ps` shows `healthy` once it is up.
